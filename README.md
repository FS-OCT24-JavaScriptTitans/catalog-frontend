## Project Description

Catalog Frontend is a modern web application for browsing and ordering gadgets. The project includes several functional pages that provide a convenient user experience, such as authorization, working with the shopping cart, and managing favorite products.

### Main Pages:

- **Authorization**: Supports login via Email and Google.
- **Shopping Cart**: Allows adding, viewing, and editing products.
- **Orders**: A page for viewing order history.
- **Favorite Gadgets**: Saves user-selected products.
- **Contacts**: A page with contact information.
- **Home Page**: The main product catalog.
- **Rights Page**: Information about site policies.

## Technologies Used

- **React**: For building components and rendering.

## How to Run the Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/FS-OCT24-JavaScriptTitans/catalog-frontend.git
   ```

2. Navigate to the project folder:

   ```bash
   cd phone-catalog
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the project in development mode:
   ```bash
   npm start
   ```

The project will be available at: `http://localhost:5173`

## Scripts

- `npm start` — Run the project in development mode.
- `npm run build` — Build the project for production.
- `npm run preview` — Preview the built project.
- `npm run lint` — Check the code using ESLint.
- `npm run lint:fix` — Automatically fix ESLint errors.
- `npm run prettier` — Check code styles using Prettier.
- `npm run prettier:fix` — Automatically format code with Prettier.
- `npm run stylelint` — Check styles.
- `npm run stylelint:fix` — Automatically fix style issues.
- `npm run format` — Automatically format code and styles.
