# Tutorial on npm Scripts

This tutorial explains the key npm scripts defined in your `package.json` and how to use them. These commands assist with development, testing, and maintaining code quality.

## **Scripts**

### 1. **Start the Project**

```bash
npm start
```

### 2. **Build the Project**

```bash
npm run build
```

- Runs TypeScript compilation (tsc -b).
- Builds the project for production using vite build.

### 3. **Preview the Production Build**

```bash
npm run preview
```

Launches a local server to preview the production build generated by the build command.

### 4. **Lint JavaScript/TypeScript Code**

```bash
npm run lint
```

- Runs ESLint on the ./src directory.
- Ensures unused directives are reported.
- Fails the process if any warnings are found (--max-warnings 0).

### 5. **Fix Lint Issues**

```bash
npm run lint:fix
```

Automatically fixes linting issues wherever possible using ESLint.

### 6. **Check Code Formatting with Prettier**

```bash
npm run prettier
```

Checks if the code in the ./src directory adheres to the Prettier formatting rules.

### 7. **Fix Code Formatting with Prettier**

```bash
npm run prettier:fix
```

Automatically formats the code in the ./src directory according to Prettier rules

### 8. **Check CSS/SCSS Style Issues**

```bash
npm run stylelint
```

Runs Stylelint on the ./src directory to check for CSS/SCSS code style issues.

### 9. **Fix CSS/SCSS Style Issues**

```bash
npm run stylelint:fix
```

Automatically fixes CSS/SCSS code style issues using Stylelint.

### 10. **Format the Entire Codebase**

```bash
npm run format
```

Runs the following commands sequentially:

- npm run prettier:fix: Fixes code formatting issues.
- npm run stylelint:fix: Fixes CSS/SCSS style issues.
- npm run lint:fix: Fixes JavaScript/TypeScript lint issues.

### 11. **Prepare for Husky**

```bash
npm run prepare
```

Sets up Husky to enable Git hooks for tasks like pre-commit linting or formatting.

## **Common Workflows**

**Check Code Quality**

```bash
npm run lint && npm run prettier && npm run stylelint
```

**Fix All Issues**

```bash
npm run format
```

**Build and Preview**

```bash
npm run build && npm run preview
```
